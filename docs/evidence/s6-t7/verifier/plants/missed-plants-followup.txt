# S6-T7 verifier: what each plant the Zig suite missed does, measured with the plant's ReleaseSmall library
# (zig build lib in the plant's tree and caches).

parity_v1 (overlap k = 1 read as a gap of 0): NOT EQUIVALENT.
  No file of the six corpora or the edge corpus has a recipe value 1 (counts: j2 0, fixtures 0, family 0, timing 0,
  prose 0, tamil 0, edge 0). corpora/k1_gen.py writes five files; indexed by the head's searchd, three of them have
  recipe value 1 (b.txt 17, c.txt 20, e.txt 1).
  head library, whole-file read_span:      a.txt equal; b.txt equal; c.txt equal  (d.md, e.txt: over the 400-line cap in one call)
  parity_v1 library, same reads:           a.txt equal; b.txt refused (SourceFileLengthMismatch); c.txt refused; e.txt refused
  head and main, every file in 400-line pieces and outline: all equal to disk, answer digest identical (7d3f3d280f480dec).
  => the suite has no file with a 1-byte overlap; a reader bug on v = 1 would refuse real files and pass every test.

overlap_bound_removed (the walk's "k > pos" rule dropped): caught only by the SHA-256.
  damage case s_overlap_isolated (dmg.py: an overlap k = pos + 1 with the record's length lowered by k, so the residual
  total still adds up): head: every outline/read_span refused (InvalidFileTable, the walk);
  plant: the walk accepts, the one file is refused at read (SourceFileSha256Mismatch), no wrong byte returned.
  => the rule is not tested on its own; the builder's ruling 11 cases that break it also break the residual total.

shared_cap_check (a front-coding prefix above 255 accepted): harmless, untested.
  damage case d_shared_256 (edge corpus: two paths sharing more than 255 bytes; shared written 256 with the suffix one
  byte shorter, so the decoded path is unchanged): head refuses the open (InvalidFileTable); plant opens and answers,
  every read equal. => the "at most 255" rule has no test.

contained_pos (locate without the max): equivalent on every input found.
  Every contained chunk in the corpora ends exactly at the covered position (k == L): prose 4, fixtures 190, edge 1,
  k1 313, family 0; none with k > L. Indexed by the plant (ss_index_folder) and read back with the head library:
  fixtures 229/229 files equal, prose 10,000/10,000 equal.

carry_len_only (the update's chunk identity check reduced to lengths): reachable only for a file whose bytes did not
  change (previous_v2 is set only when the bytes and SHA-256 match) and whose chunks changed to texts of the same
  lengths. plants/carry_demo.py (a same-length edit inside a chunk, update by the plant over a head index):
  45/45 files equal (the edited file is not a carry candidate). No input found that reaches it.

parity_v0 (gap 0 read as overlap 0): equivalent by construction (both emit the whole chunk).
