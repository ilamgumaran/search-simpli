# S2-T13 · A cosine that is not a number must not reach the ranker

**State:** ready · **Series:** S2 (found by the S2-T3 verifier, finding 1) · **Depends on:** S2-T4 · **Size:** XS · **Builder:** Sonnet 5 · **Tester:** Opus

A query vector whose components are finite but large (around 1.8e19 and
above) passes the finite check, and the cosine then overflows to NaN. NaN
breaks the sort comparison, so the order of the affected chunks is undefined:
the S2-T3 verifier saw 111 of 120 such calls ranked differently from the dense
path, against 120 of 120 for ordinary vectors. Neither order is wrong by the
contract because the contract never said; this task says. The app pins
lexical mode, so nothing on the phone is exposed today.

## Acceptance criteria
1. At the ABI, a query vector whose L2 norm is not finite (overflow, NaN, ±inf
   in any component) is rejected with `SS_ERR_INVALID_ARGUMENT` and a one-line
   message, in every mode that reads it (lexical mode still ignores the vector
   and still reports `vector_ignored`; say in the Report whether lexical mode
   validates it anyway, and why).
2. On import (`ss_import_json`, `searchd import-json`) and on folder indexing
   with vectors, a document vector whose norm is not finite is rejected with
   the same error and nothing is published.
3. The cosine itself is computed so that finite inputs cannot overflow
   (normalise before the dot product, or accumulate in `f64`): a unit test
   with components at `f32` extremes shows a finite score.
4. **Bar (a):** query output for every valid vector is byte-identical to the
   previous library on S2-T3's semantic and tie-heavy sets and on the 10k
   hybrid capture (`scripts/capture_query_outputs.py`, profile off and on).
5. **Plant:** with the norm check removed, the rejection test fails; with the
   overflow-safe cosine reverted, the extremes test fails.
6. Header, `docs/zig-engine-api.md` and the Dart `query` doc say what a valid
   vector is. Contract unchanged (an error on an input that never had a
   defined result).
7. All five suites green after the Report; libraries rebuilt last.
