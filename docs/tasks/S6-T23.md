## Why

"Take all the text in first." The engine reads 19 extensions. On the judged
set's folder 24 of 264 files are never read (logs, CSV and TSV tables, a shell
script, an XML file, four files with no extension), and none of the 23
questions whose answers sit only in such files is answered. The usage scenarios
of 22 Nov found the same from the outside
([scenarios](../testing/scenarios-engine-2026-11-22.md): I02, I10): `.markdown`
is not read although the engine's own documents name it. A file that is never
read cannot be found.
