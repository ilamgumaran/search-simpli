**State:** Part 2 built and reported by the builder, 23 Nov 2026, everything but timing done ([Report (Part 2)](#report-part-2)); the timing orders committed and pushed, the runs wait for the orchestrator; Part 2 ruled (the note accepted, rulings below, 22 Nov 2026); Part 1 (the design note) built and reported by the builder, 22 Nov 2026, from `main` at `8ffc41c`; filed by the orchestrator, 22 Nov 2026, from `main` at `2d060d2` · **Depends on:** [S6-T22](S6-T22.md) (the judged set this is measured on) · **Plan:** [objective plan](../plans/2026-11-16-objective-plan.md), [the priority of 22 Nov 2026](../plans/2026-11-16-objective-plan.md#the-priority-set-by-the-maintainer-on-22-nov-2026), step H2

## Why

"Take all the text in first." The engine reads 19 extensions. On the judged
set's folder 24 of 264 files are never read (logs, CSV and TSV tables, a shell
script, an XML file, four files with no extension), and none of the 23
questions whose answers sit only in such files is answered. The usage scenarios
of 22 Nov found the same from the outside
([scenarios](../testing/scenarios-engine-2026-11-22.md): I02, I10): `.markdown`
is not read although the engine's own documents name it. A file that is never
read cannot be found.
