## Rulings
1. **`searchd mcp <dir> [--roots] [--labels] [--baseline] [--allow-write] [--allow-file-reads]`** over stdio as §11: `initialize` (the pinned `protocolVersion` constant in `zig/src/mcp.zig`, recorded in the Report), `notifications/initialized`, `ping`, `tools/list`, `tools/call`, `resources/list`, `resources/read`, `resources/templates/list`. Tools: `--baseline` lists exactly CAP-13's four; default lists the eight read tools; `--allow-write` adds `apply_changes`. Each tool's `inputSchema` is the S3-T5 request schema verbatim. `tools/call` returns the canonical result JSON as `structuredContent` and as one `text` block. Resources: `search://{root_id}/{path}` read through `read_span`'s limits (whole file when ≤ the caps, else an error naming them). The scope comes from the command line only; a request carrying `principal_labels` or `query_vector` is rejected (CAP-13 FR-13).
2. **Conformance client** (`tests/mcp_client.py`, standard library): initialize handshake, tools/list, tools/call for every tool, resources/list and resources/read, malformed line, unknown method, a write call without `--allow-write` (rejected), batch cancellation of nothing (MCP has no cancellation to honour here; `ping` answered); run against the fixture.
3. **Parity.** For the fixture judgments, the canonical JSON inside `structuredContent` equals the RPC server's result for the same request after the transport envelope is removed; 100% of cases, any mismatch fails the test (CFT-22).
4. **Measured in the Report (§13 profile):** adapter overhead p95 over the direct Zig call for `find` and `search_knowledge` (CAP-13's gate ≤ 5 ms); startup time; the pinned protocol revision string.
5. **Docs.** `docs/mcp-server.md` (new): how an MCP host launches it (the command line, the stdio contract, the scope flags), what it never does (no network, no model, no writes without the flag), the baseline mode; CAP-13 status updated to "realized by S3-T6" with the register row and `IMPROVEMENT-BOARD.md` I-01 closed.
6. **Diff scope.** `zig/src/mcp.zig` (new), `cli.zig` (the `mcp` command), `tests/mcp_client.py` (new), `tests/test_mcp.py` (new), `docs/mcp-server.md`, `docs/requirements/cap-13-mcp-adapter.md` (status), `docs/requirements/README.md` (status rows), `IMPROVEMENT-BOARD.md`, `PROJECT-STATE.md`.
