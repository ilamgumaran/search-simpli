## Problem and scope

The existing GitHub job sets `SEARCH_SIMPLI_NO_ZIG=1` intentionally. Python reference checks run, but native engine, C ABI and real CLI process regressions can escape CI. Native baseline verification found two real Linux failures: directory publication calls `fsync` on Zig's `O_PATH` handle (`EBADF`), and the C harness lacks the feature-test definition required to declare `mkdtemp` under C11. Fix these compatibility defects and add a separate Linux native job. Preserve the dependency-free job, existing test assertions and contracts; regenerate shipped libraries from the changed source.

## Acceptance criteria

1. On pull requests and main pushes, the additional job installs exactly Zig 0.16.0 for Linux x86_64 from the official HTTPS archive, verifies SHA-256 **before extraction**, and checks the executable version. The published archive checksum is `70e49664a74374b48b51e6f3fdfbf437f6395d42509050588bd49abe52ba3d00`. Use temporary runner storage, bounded job duration and read-only repository permissions. Never bypass TLS/checksum checks.
2. Directory synchronization obtains a readable descriptor for the same directory on Linux/Android rather than syncing an `O_PATH` handle. Close any owned descriptor on every exit. Preserve both durability barriers, EINTR retry, genuine sync-error propagation, and post-MANIFEST retention. Keep macOS behavior intact. Fix the C harness's POSIX declarations. The job runs the existing `zig build test -j2 --summary all` and `zig build test-abi -j2 --summary all` in `zig/`, then `python3 -m unittest discover -s tests -v` from the root with `SEARCH_SIMPLI_LIBRARY_PATH`, `SEARCH_SIMPLI_NO_ZIG` and `SEARCHD_BINARY` unset. Real CLI process tests build their own executable. Failures fail the job; the Python-only job remains intact.
3. Reproduce installation and native checks locally, record counts/exits/skips, and verify the install shell rejects a deliberately incorrect checksum before extraction. Independently reproduce the real baseline `EBADF` and verify real directory `fsync` succeeds after the fix. Existing publication fault tests must still pass, including the failed barrier after MANIFEST. A plant restoring the old directory-sync call must fail the real-directory regression. Rebuild packaged libraries last with the pinned toolchain and checksum-verified NDK; record sizes/hashes/stamp and preserve contract 1.2.0. Run the requirements validator and doc/path checks after writing the Report. GitHub execution and macOS/Android device execution require separate evidence.
