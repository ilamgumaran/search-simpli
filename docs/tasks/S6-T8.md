## Source

After step 2 the 10k timing index is 2.17 times its corpus. The highlight offsets `find` reads (per token, where it starts and how long it is, in codepoints) are stored as varints. [`docs/index-size.md`](../index-size.md) § C5b settles the design: per token one byte, two 4-bit fields (the zigzag gap in codepoints between the previous token's end and this token's start; the token's length), a field value of 15 escaping to a varint after the byte; the token count per document as a varint. Measured by the S6-T3 prototype: −1,195,645 B (timing 10k), −3,229,866 B (prose 10k), −1,198,396 B (Tamil 10k). Positions stay mandatory and the offsets stay (C5 and C6 were ruled out on 16 Nov); what `find` returns does not change.

## Rulings

1. **Format document first, then the build, in one phase.** Write `docs/offsets-format-vN.md` (name and version by the repository's convention; if the offsets live inside the lexical segment, a new lexical version document instead) so a reader can implement a decoder from it alone: the layout byte for byte, the manifest version and flag bit, both escapes and their order when both fields escape, the zigzag form, every validity rule (bounds, counts, no byte left over, an escape that overruns, a decoded offset past the text), and the worked example of at least one document with an escape in each field. **Stop and report before building only if** the contracts or the C header would have to change, the measured saving on a re-encoded 10k corpus is under half of S6-T3's figure, or the design above cannot be implemented as written; otherwise go on.
2. **One format version, the previous readers kept.** The new library opens an index written by `main` at `62324f9`, and one written before S6-T7 and before S6-T4, and answers identically; it writes the new format at the first publish, one whole generation, byte-identical to a fresh index. An older library refuses the new index with a clear error through the CLI and the C ABI and leaves the files byte-identical. This is the third one-way step: the migration note goes in the Dart CHANGELOG and the 03-next pin row, beside the other two.
3. **Same answers.** Every surface (CLI, JSON-RPC, MCP, `ss_query`, `find` in `words`, `phrase` and `prefix`, `read_span`, `outline`, `list_files`, `searchd search`) byte-identical to `main` on J2, the fixtures, the family fixture and the three 10k corpora, fresh and on an old-format index updated once. Highlights in particular: every `find` hit's offsets equal `main`'s on a query set that includes Tamil, combining marks, tokens of 15 codepoints and longer, gaps of 15 codepoints and longer, and a token at the very start and very end of a chunk.
4. **Expectations, stated here before measuring.** Size: the offsets section within 3 % of S6-T3's C5b figure on each 10k corpus. Open time and memory after open: not above `main`. `find`, the changed path: not slower than `main` on any cell by the rule of 2026-11-17 in [ROLES](../process/ROLES.md). One-file update and first publish from the old format: not slower than `main` by more than 2 %. A missed expectation is reported as missed and is the maintainer's to accept; it is not tuned away and not reworded.
5. **Timing** by the rule of 2026-11-17: five gated runs by the verifier (the builder takes two for information), Latin-square orders written before the first run, controls `main2` and `main` plus never-run code, one sized to this task's compiled-code delta. When timing open, each build opens its own copy of the index (S6-T7's verifier found that a shared copy favours whichever build opens it first).
6. **Damage and crash.** Every validity rule in the format document has a test that violates it with the checksum recomputed and is refused on that rule's own error, including each last-element boundary and a leftover byte. A publish killed at any point leaves a whole old or whole new generation.
7. **Tests that the earlier steps' verifiers found missing, required here from the start:** each boundary value has a fixture (field values 14, 15 and 16 in each field; a negative gap if the tokenizer can produce one, and if it cannot, say why with the code reference; a document with zero tokens; a document with one); the new test files are referenced so `zig build test` runs them, shown by breaking one assertion. Plants, each in its own scratch copy and Zig cache, at least: the two nibbles swapped; the escape threshold 14 or 16; the escape order swapped when both fields escape; zigzag decoded as unsigned; the count off by one; the old reader removed; a leftover byte accepted.
8. **Natives, suites, CI, documents** as S6-T7: the three libraries rebuilt and stamped in the same commit as the library change; Zig Debug and ReleaseSmall, C ABI, Python with and without Zig, Dart, J2 gate; layers, requirements and home-path checks; CI green on the final commit. Documents: the format document, `docs/manifest-format-v2.md`, `docs/index-size.md` (step 3's status and the measured table), README measured lines, `PROJECT-STATE.md`, 03-next (D2-3 done; the pin row carries all three one-way notes), Dart CHANGELOG and patch version. Every percentage written is computed from measured bytes and given to one decimal. Contracts and the C header do not change. `IMPROVEMENT-BOARD.md` is not edited.
9. **Layers.** The coding is core; no interface file learns the format; `scripts/check_layers.py` clean with no new allowed import.
