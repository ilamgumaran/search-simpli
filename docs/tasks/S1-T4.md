## Acceptance criteria
1. Dart binding for `ss_index_folder` (`SearchSimpli.indexFolder(dir, path, opts)` returning a typed report) with a test on the Mac and in the example app's instrumentation test on the emulator (private storage).
2. macOS/Linux library loading is package-relative (resolved from the package root via `Isolate.resolvePackageUri` or the `native/` layout), so a path dependency works without `SEARCH_SIMPLI_LIBRARY_PATH`; the env var stays as an override; README install steps followed literally must pass.
3. Report JSON lists the paths of `unreadable` and `too_large` files; `skipped` split into `unchanged` and `budget_exhausted`; an empty folder or last-file deletion publishes an empty generation instead of `NoDocuments`; `lifecycle.scan` knows `INDEX-STATE.json`; a file grown past the cap is reported as `too_large` AND its old chunks tombstoned (never silently kept or lost); tests for each.
4. Docs: the four "API 37" labels corrected to API 34 (Android 14); `docs/incremental-indexing.md` rewritten to the shipped design; README full-rebuild figure re-measured; `gen_timing_corpus.py` dead code removed; the four schema-optional fields get Dart members.
5. All suites green (`zig build test`, `test-abi`, `lib`, Python, `dart test`), run after the Report; prebuilt libraries rebuilt and committed with sizes.

2. $ searchd index notes --out idx --update --max-file-bytes 200
   {"generation":2,…,"unchanged":1,"budget_exhausted":0,"too_large":1,"unreadable":0,
    "too_large_paths":["grows.md"],"unreadable_paths":[],"documents":1,"terms":7,"postings":7}
   query "quantum" -> []                       # old chunks gone, not silently kept
   query "ranking"  -> alpha.md                # the unrelated file untouched
   INDEX-STATE.json -> files:[{"path":"alpha.md",…}]      # its state entry dropped
3. $ searchd index notes --out idx --update --max-file-bytes 200
   {"generation":3,…,"unchanged":1,"too_large":1,"too_large_paths":["grows.md"],"documents":1}

   {"generation":4,…,"added":1,"unchanged":1,"too_large":0,"documents":2}
   query "quantum" -> grows.md                 # re-admitted cleanly

state entry are dropped, it stays dropped on the next run, and it comes back
as `added` when it shrinks. The `unreadable` policy differs as documented

### Non-blocking findings

1. **`max_file_bytes`/`max_total_bytes` are silently ignored on a
   non-`update` run**, while both the C header's options table and the new

   read, and is reported (and tombstoned) under `tooLarge`/`tooLargePaths`").
