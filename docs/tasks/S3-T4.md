## Rulings
1. **C ABI** as §9: `ss_find`, `ss_outline`, `ss_read_span`, `ss_list_files`, `ss_roots`, `ss_apply_changes`; `ss_query` and `ss_evidence` accept `roots` in options; the ten v1 functions unchanged; `ss_evidence` items gain `section_path`, `neighbours`, `root_id`; `ss_status` gains `generation`, `roots`, `pending`, `has_source`, `has_positions`, `chunkers`. `zig/include/search_simpli.h` documents every request and result field; `zig/tests/abi_test.c` covers each new function including the error paths (`CAPACITY` for absent source/positions, `INVALID_ARGUMENT` for a stale cursor, `NOT_FOUND` for an unknown path).
2. **Dart binding** (`bindings/dart/search_simpli`): `find`, `outline`, `readSpan`, `listFiles`, `roots` instance methods, `applyChanges` static; typed result classes; `ContractsVersionMismatchException` for a native library without the new symbols; `dart test` covers each against the fixture through the native library on the Mac.
3. **CLI `searchd`**: `find <dir> "<query>" [--mode words|phrase|prefix] [--roots] [--page-size] [--cursor] [--json]`, `outline <dir> <root_id> <path>`, `read-span <dir> <root_id> <path> <start> <end> [--context N]`, `list-files <dir> [--root] [--prefix] [--status]`, `roots <dir>`, `apply <dir> --changes <file> [--expect-generation N] [--allow-file-reads]`; human output and `--json`; exit codes as today.
4. **RPC server** (`zig/src/rpc.zig`, `docs/tool-protocol.md`): methods `find`, `outline`, `read_span`, `list_files`, `roots` beside the four existing; `apply_changes` only with `serve --allow-write`; unknown fields rejected as today; the scope (`--roots`, `--labels`) from the command line, `principal_labels` in a request still bounded as today for the raw service. `contracts/CONTRACTS_VERSION` → 2.0.0; `contracts/tool-request` v2 documents every method; the Dart `search/contracts` types in the consumer app are regenerated at its pin bump (noted in the Report, not done here).
5. **Tests.** ABI 6 new + existing 16; Dart; CLI (subprocess tests in Python, standard library); RPC: a request per method with scope, paging, caps and error cases; a parity test that the CLI `--json`, the RPC and the Dart binding return the same canonical JSON for the fixture judgments.
6. **Measured in the Report:** per-surface overhead over the core for `find` on the fixture (p50), the native library sizes before/after for the three platforms (built in S3-T8; this task measures macOS only).
7. **Diff scope.** `zig/include/search_simpli.h`, `zig/src/abi.zig`, `rpc.zig`, `cli.zig`, `zig/tests/abi_test.c`, the Dart package (`lib/`, `test/`, `CHANGELOG`), `contracts/`, `docs/tool-protocol.md`, `docs/zig-engine-api.md`, `docs/zig-rpc-service.md`, `PROJECT-STATE.md`.
