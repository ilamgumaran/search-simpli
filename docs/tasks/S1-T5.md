**State: built.**

### Criterion 1: Apply caps on non-update runs

Modified `indexer.indexFolder` to accept a `caps: Caps` parameter and apply the size caps (max_file_bytes, max_total_bytes) the same way `indexFolderIncremental` does. A file over `max_file_bytes` is not read and is reported as `too_large` with its path listed in `too_large_paths`.

- **Zig test:** `indexer.test.indexFolder applies max_file_bytes cap on a full rebuild` — a 41-byte file with a 10-byte cap is reported `too_large: 1` and not indexed (`added: 0, documents: 0`). The empty generation is still published and queryable.
- **CLI:** `searchd index --max-file-bytes 10 <folder> --out <dir>` now enforces the cap on the full rebuild.
- **ABI:** `ss_index_folder(dir, folder, {"max_file_bytes": 10})` applies the cap on both `update: false` (full rebuild) and `update: true` (incremental).

Regression test (fix reverted):
- Reverted: Changed line 190 from `if (size > caps.max_file_bytes)` to `if (false) { // disabled cap check`
- `zig build test` runs: `indexer.test.indexFolder applies max_file_bytes cap on a full rebuild` fails:
  ```
  error: expected 0, found 1
  ``` (expected `added: 0` but got 1; the file is now indexed despite the cap)
- Restored: File now passes again.

### Criterion 2: Full rebuild writes INDEX-STATE.json

Modified `indexer.indexFolder` to write `INDEX-STATE.json` after publishing the generation. This file persists the hash and size of each indexed file, so the first `--update` after a full rebuild will recognize unchanged files instead of re-reading and re-chunking everything as `added`.

- **Zig test:** `indexer.test.full rebuild writes INDEX-STATE.json` — after a full rebuild, loads the persisted state and verifies it has 1 entry with path "note.md".
- **Updated `docs/incremental-indexing.md` §Per-file state** to state that full rebuilds write INDEX-STATE.json (S1-T5 criterion 2).

Regression test (fix reverted):
- Reverted: Removed lines that save INDEX-STATE.json (`try incremental_state.save(...)`)
- `zig build test` runs: `indexer.test.full rebuild writes INDEX-STATE.json` fails:
  ```
  error: expected 1, found 0
  ``` (expected state to have 1 file, but it's null; the state file wasn't written)
- Restored: File now passes again.
