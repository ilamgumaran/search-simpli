# S1-T16 · NFC recomposition is quadratic in the text length

**State:** ready (2026-10-10) · **Series:** S1 · **Depends on:** S1-T15 · **Size:** S · **Builder:** Sonnet 5.5 · **Tester:** Opus 5.5

**From the S1-T15 Verdict, finding 1.** The recomposition step in `zig/src/nfc.zig` grows with the square of the text length, and since S1-T15 it reaches Korean: a 256 KB single line holding at least one combining mark went 11 ms → 1.1 s, 1 MB 48 ms → 17 s; `searchd index` on such a file 19 ms → 1,220 ms. Chunks are at most 1,600 characters, so normal text never sees it, but a query or a single very long line can. The M1's S2-T11 listed a "linear NFC step" candidate; this is it.

## Rulings
- Recomposition becomes **linear**: one pass with a bounded look-back (the last starter and the combining classes since it), as UAX #15's canonical composition algorithm describes; no rescans of the already-composed prefix.
- Output byte-identical to today's on every case `scripts/nfc_compare.py` covers (0 differences stay 0) and on the S1-T15 tester's random mix; every golden byte-identical; analyzer id unchanged.

## Acceptance criteria
1. **Bar, written first:** the S1-T15 tester's timings reproduced on `origin/main` (a 256 KB and a 1 MB single Korean line with one mark; `searchd index` on the 1 MB file), then on the branch: ≤ 2× the mark-free time at every size (so ≤ ~25 ms and ≤ ~100 ms), and growth linear between 256 KB and 1 MB (×4 ± 25 %). Best of 3, all runs listed; never a single wall-clock threshold as the only test: the test asserts the growth ratio and a generous absolute ceiling.
2. `nfc_compare.py`: 0 differences; the 200,000-string random mix: 0 differences; the S1-T15 specific-case table 27/27; a new case for the blocking rule in Tamil (the tester's finding 3).
3. Every golden and the 2,762 captured outputs byte-identical; `import_parity.py --baseline` PASS; Dart conformance 8/8 and 10/10.
4. Libraries rebuilt and stamp re-stamped via `tool/build_native.sh` last; `CONTRACTS_VERSION` unchanged; five suites green; paths redacted.
