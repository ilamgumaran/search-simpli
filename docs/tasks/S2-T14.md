# S2-T14 · Generation numbers never go backwards; two small leaks

**State:** built · **Series:** S2 (found by the S2-T12 verifier, findings 1 and 2) · **Depends on:** S2-T12 · **Size:** XS · **Builder:** Sonnet 5.5 · **Tester:** Opus

**A.** After a lost `MANIFEST` the next publish numbers its generation from
the start again: with only generation 2 on disk and `MANIFEST` deleted, the
recovery publishes **generation 1**. The generation-2 files then sit as
orphans until the counter passes them, and a caller that reopens only when
the generation number rises (a reasonable thing for the app to do) would
never see the recovered index. Older than S2-T12; `main` before it did the
same.

**B.** The Dart `indexFolder` allocates two small native strings before
`options.toJson()` throws on an invalid `keepGenerations`, outside the
`try/finally`, so they leak on that error path.

## Acceptance criteria
1. A publish into a directory with no readable `MANIFEST` numbers the new
   generation **above the highest canonical section file present**
   (`documents-N.hybseg` / `lexical-N.hyblex`, complete or not) and above any
   generation `INDEX-STATE.json` names; a fresh directory still starts at 1.
   `generation_alloc.zig` (or wherever the counter lives) is the one place;
   say in the Report what happens at `u64` max (the S1-T8 verdict recorded a
   panic there: not this task's job to fix, but it must not get worse).
2. **Bar (a):** the S2-T12 verifier's case: only generation 2 on disk,
   `MANIFEST` deleted, `--update` → generation **3** with
   `recovered: missing_manifest`; `lifecycle.scan` then shows generation 2 as
   superseded, not orphaned; with `keep_generations: 1` it is pruned on that
   run after the new `MANIFEST` is visible. Repeat through `ss_index_folder`
   and through `ss_import_json`.
3. Dart: encode the options before allocating any native string; a test with
   a counting allocator or a fake binding shows no allocation on the
   `ArgumentError` path.
4. **Plants:** numbering restored to the old rule → the criterion-2 test fails
   (`expected 3, found 1`); the Dart reorder reverted → its test fails.
5. `docs/generation-lifecycle.md` states the numbering rule.
6. All five suites green after the Report; libraries rebuilt last.
