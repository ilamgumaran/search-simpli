# S6-T15: two follow-ups of the file move (a test no root names; old paths in comments)

**State:** filed by the orchestrator, 20 Nov 2026, from `main` at `50ffbfd` · **Depends on:** [S6-T14](S6-T14.md) (its Verdict's findings 1 and 2)

## Why

After the move a test runs only if a module root names its file. The S6-T14
verifier added a failing test file that no root named: `zig build test` passed
with the usual totals and the layer checker said OK. A contributor's new test
can be silently skipped. Separately, twelve comments still name paths that no
longer exist.

## Rulings

1. **A test file that no root reaches fails the checker.** `scripts/check_layers.py`
   (or a small checker beside it, run in CI where the layer checker runs) fails,
   naming the file, when a `.zig` file under `zig/src/` that holds a `test`
   block is reached from no test step's root. Shown by: the verifier's planted
   file fails it; removing any one existing name from a module root fails it;
   today's tree passes. Read from Zig tokens as the layer checker reads imports,
   so a `test` in a comment or string is not counted. Tests for the checker in
   the place its existing tests live.
2. **The documents say where a test goes and how it is made to run:**
   CONTRIBUTING and `docs/layers.md`, one short paragraph each; CONTRIBUTING's
   stale suite counts are corrected to measured ones or replaced by wording
   that does not go stale.
3. **Old paths in comments** are corrected in the ten places outside the C
   header (bench and tool usage comments, the generator's regenerate line and
   the generator that emits it). Comments only: no code token changes. The two
   comments in the C header are **not** touched; they are listed in the Report
   for the maintainer.
4. **Natives.** If a changed comment sits in a file the source digest covers,
   `SOURCE-SHA256` is restamped in the same commit and the rebuilt natives are
   shown `cmp`-identical to `main`'s (a comment cannot change them; if any byte
   differs, stop). Dart stays 0.9.4.
5. **Stop before** any change to a function body, the C header, a contract, a
   format or an answer.

## Notes for the builder

As [S6-T14](S6-T14.md)'s notes. No timing is needed if the natives and
`searchd` ReleaseSmall are byte-identical to `main`'s; say so.
