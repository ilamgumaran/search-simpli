## Rulings
1. **Fixture** `fixtures/family-folder/` exactly as §12: three roots (`school/`, `home/`, `laptop/`), ≥ 40 files (≥ 25 Markdown), front matter (YAML subset), ATX and Setext headings to depth 3, lists, two fenced blocks (one longer than 1,600 codepoints), one deterministic file > 1 MB (a generator script committed, the file committed too if under 2 MB, else generated in the test), two files with identical content under different names, a CRLF file, a file with no final newline, a BOM file, a Tamil file, a repeated-tokens file, an empty file. Invented content only (invented people, schools, places); no real names, addresses or dates that identify anyone.
2. **Judgments** `fixtures/family-folder/judgments.json` version 2: the 13 UC-007 scenarios (each with the expected hit set `{root_id, path, start_line, end_line}` for retrieval questions, the expected section path for structure questions, the expected emptiness for the newt question) plus five phrase, five prefix, five outline and five `read_span` cases (`read_span`: the sha256 of the expected text, computed from the files by the generator). A README in the fixture explains each case and names the known chunk-local phrase miss (CAP-19 open decision 1) as an expected miss.
3. **Runner.** `scripts/relevance_smoke.py --pack family-folder` runs the pack through the Python reference now (phrase/prefix/outline cases marked "not yet implemented" and skipped with a count until S3-T1/T2 land) and prints UC-007's metrics; CI runs it on Linux. The pack is **frozen**: a later task that needs a judgment changed must say so in its Report and the change is a reviewed commit, not a silent edit.
4. **Tests.** `tests/test_family_folder_fixture.py`: the fixture matches §12's inventory (counts, the special files present), the judgments reference existing paths and line ranges within each file's line count, the sha256 values match the files.
5. **Diff scope.** `fixtures/family-folder/` (new), `scripts/relevance_smoke.py`, `tests/test_family_folder_fixture.py` (new), `.github/workflows/checks.yml` (the pack in the Python job), `PROJECT-STATE.md`.
