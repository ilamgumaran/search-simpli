## Source

J2's 95 answerable questions sit at 0.832 right-file-first, and the rules that got them there also return hits for questions nothing answers. `painting the fence` returns ten hits, the first a model-making file reached through `paint` and through `the` in a file name. `skating` reaches `saving`, `setting`, `sorting`. `hopping` can generate `hopes`; `evening` can generate `even`. None of this is measured as a rate: J2 holds a handful of negatives, recorded as information and gated by nothing. This task first makes irrelevant hits measurable, then tries three narrow rules one at a time, and ships only what the measurement supports.

  1. for such a *b*, *b*+`ed`, *b*+`ing` and *b*+`es` are dropped (*b*+`es` kept after `s`, `x`, `z`, `ch`, `sh`);
