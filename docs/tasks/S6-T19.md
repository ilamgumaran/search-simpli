# S6-T19: tests that write a generation by hand move out of operations and interfaces

**State:** filed by the orchestrator, 21 Nov 2026, from `main` at `d9df56d` · **Depends on:** [S6-T16](S6-T16.md) (it listed this as a follow-up), [S6-T15](S6-T15.md) (the two test guards) · **Plan:** [objective plan](../plans/2026-11-16-objective-plan.md), section B (follow-ups to B3)

## Why

[core-api](../core-api.md), "Names that look like internals", lists names that
are in `core.api` only because tests written beside the code in `ops/` and
`interfaces/` use them: `analyzer_v2.analyzer_id` and `manifest.decode`
("test-only names"), and part of "writing a generation by hand" (the section
encoders, `postings.*`, `manifest.create`/`encode`, `lifecycle.publishSerialized`
as used by tests in `interfaces/abi.zig`, `interfaces/rpc.zig` and
`ops/service.zig`). Cross-layer tests in `tests/` may use core internals; tests
beside the code may not, so each such test keeps a name public.

[S6-T17](S6-T17.md) is verified and awaits the maintainer; keep clear of its
files (`generation_alloc.zig`, `manifest_read_test.zig`).

## What

1. **Measure first.** A table, committed as evidence: every `core.api` name used
   in `ops/` and `interfaces/`, split by whether a non-test declaration uses it
   or only `test` blocks do. The names used only by tests are the candidates.
2. **Move the tests** that use candidate names to `zig/src/tests/`, importing
   what they need the way the cross-layer tests there do. A test that needs a
   private declaration of its file is not moved: report it, with the declaration,
   and leave its names in `api`.
3. **Drop from `core.api`** every name nothing in `ops/` or `interfaces/` uses
   after the move. Update `docs/core-api.md` (list, counts from the checker's
   output, the follow-up items struck or narrowed with this task's number).
4. **`searchd init-demo`** (`interfaces/main.zig`) is not a test and is **not**
   changed here; the names it needs stay, and the Report says which those are.

## Rulings

1. **No shipped code changes.** Only `test` blocks move, and `core.api` loses
   aliases. No function body outside tests changes. The three native libraries
   and `searchd` ReleaseSmall are expected byte-identical to `main`'s (macOS
   1,006,456 B, Android 966,800 B, iOS 971,424 B, `searchd` 1,151,208 B, the
   last compared with a `searchd` built from `main` at `d9df56d`); if any
   differs, stop and report. `SOURCE-SHA256` is restamped in the same commit as
   any change to its inputs. Byte-identical binaries mean no timing is owed.
2. **The same tests run.** Every test on `main` runs on the head, by name, in
   Debug and ReleaseSmall: 592 in total before and after. A moved test keeps its
   name and body apart from its imports. Per-step totals change (the Report gives
   them) and both S6-T15 guards pass.
3. **The guard** fails a planted use of each dropped name in `ops/` and in
   `interfaces/`; show it for at least three of them.
4. **Stop before:** changing a test's assertions; making a private declaration
   public so a test can move; any contract, header or format change.
