# S1-T1 · Native indexing: chunker, Unicode analyzer, standalone CLI

**State:** ready (round A, alongside S1-T0) · **Depends on:** ADR 0002 · **Size:** L · **Builder:** Sonnet 5 · **Tester:** Opus 5

## Acceptance criteria
1. `line-window-v1` chunker ported to Zig; golden test: chunk ids, line ranges, and bytes identical to the Python reference on every fixture and on `simpli-helper/packages/vizhi_core/test/fixtures/` text files (copied into `fixtures/` here, invented content only).
2. `analyzer-v2`: Unicode-aware tokenization (NFC, case folding, letters/digits by Unicode category, no ASCII-only paths), recorded as the analyzer id in segments; the ASCII analyzer stays available as `analyzer-v1`; a Tamil fixture folder (≥ 10 invented short passages) with judged queries proves Tamil works end to end; BM25 results identical between Python and Zig for both analyzers.
3. `searchd index <folder> --out <dir>` indexes UTF-8 text/markdown/source files natively (no Python), `searchd query <dir> "<text>" [--json]`, `searchd evidence`, `searchd serve <dir>` (existing JSON-RPC over stdio, plus `--http 127.0.0.1:<port>` local only); `--help` for a stranger.
4. One static binary per platform (`macos-aarch64`, `linux-x86_64`) from `zig build -Doptimize=ReleaseSafe`; sizes and a 1,000-file timing pasted.
5. README gets a "Standalone" section (install nothing: download the binary, index a folder, query); tests green.
