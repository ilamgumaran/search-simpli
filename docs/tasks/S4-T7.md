**Why.** The "Skill: the no-channel sentence names a CLI flag" row in `docs/journey/03-next.md`, filed from the consumer app's M16-T22 (5 Nov): when the app regenerated its skill text from S4-T5's `skills/folder-knowledge/SKILL.md`, two sentences in step 2 did not fit an embedded host. "An index built without the file-name channel … refuses a `filename` or `both` request with an error that names `--filename-index`" names `searchd`'s CLI option, which a library consumer cannot pass (the app enables the channel on every new index, rebuilds old ones once, and answers an explicit `filename` ask on a not-yet-rebuilt index with its own warning); "do not retry with `filename` there" assumes the model reads the engine's error rather than the host's. The skill is read by models in both hosts (the `searchd` CLI and MCP server, and apps that embed the library and regenerate the text), so its sentences must hold in both.

## Rulings
1. **Step 2's last two sentences become host-neutral.** The bullet keeps every fact and gains none: an index built without the file-name channel has no `filename_policy_id` in `index_status` and refuses a `filename` or `both` request; **the host says so in its own words** (the `searchd` CLI and MCP server answer with an error that names the `--filename-index` option of `searchd index`; an app that embeds the library answers with its own warning); then: answer from the text, and do not ask for `filename` again on that index. The string `--filename-index` stays in the bullet (the S4-T5 test `test_skill_names_the_filename_field` asserts every needle, and the test is **not** edited); the sentence that carries it must read correctly for a host that has no such option.
2. **Nothing else moves.** No other line of `SKILL.md` changes; `example_loop.py`, the contracts, the schemas and every test are untouched. `tests/test_example_loop.py` passes unchanged (the Zig-less `SkillTextTests` and, with a Debug `searchd` built by `zig build`, the `LoopOverTheFixtureTests`); the judgment pack and `scripts/check_no_home_paths.py` as in S4-T5.
3. **The record.** `docs/journey/03-next.md`: the row is struck ("done by S4-T7"); the "Consumer app: regenerate the skill at the next pin" row gains one sentence (the app regenerates again at its next pin to take S4-T7's wording; no natives, contract or binding change). `PROJECT-STATE.md`'s skill line, if it quotes the sentence, follows. No Dart package version change (the skill is not part of the package), no `SOURCE-SHA256` change (the digest covers Zig sources, the C header and the Dart binding; check with `scripts/source_digest.py` or `tool/build_native.sh`'s digest step and state the result).
