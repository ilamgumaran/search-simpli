## Problem

Automatic generation selection probes candidate section names with `statFile`'s default symlink-following behavior. A dangling symlink occupies a filename, but following it reports the missing target as `FileNotFound`. The allocator can therefore select a generation that immutable publication cannot create. A self-referential link can likewise turn a slot-occupancy check into a link-resolution error. Local folder indexing should skip an occupied entry without repairing, deleting or following it.

## Scope and acceptance

1. Probe generation-slot occupancy without following symlinks. Keep the regular-file highest-generation scan, canonical parsing, writer locking and next-free-pair rule. Explicit caller-numbered publication is unchanged.
2. Engine and real CLI/ABI regressions cover dangling and self-referential candidate entries, both document and lexical names, ordinary existing-snapshot updates, and the upper-generation limit where relevant. Verify the chosen free generation and preserve link targets, link entries and existing snapshot bytes; no automatic repair/deletion.
3. Demonstrate expected failure with the predecessor before accepting the fix. Review the actual runtime change independently; do not weaken existing assertions, retrieval judgments, public signatures or diagnostics.
4. Run the relevant Zig engine/C ABI, Python process/behavior, Dart binding and relevance checks. Rebuild matching packaged macOS/Android libraries and source stamp with the retained pinned toolchains. Record exact outcomes, skips and platform limits; cross-compilation is not device execution.
5. Run requirements/privacy/path/documentation checks, publish a PR and report actual GitHub CI. No merge or device deployment is implied.

## Rulings

This repairs an existing occupied-name/publication invariant; it adds no new retrieval capability, configuration, wire contract or ABI. The new-capability approval process is not needed for this bounded correction. Existing S1-T9 owner review, judged-benchmark decisions and S1-T20's other carried findings remain separate.

The highest-generation scan still excludes non-regular entries. Candidate probing must treat an existing entry as occupied even when its target is absent or cyclic. At a blocked final candidate the existing `NoFreeGeneration` diagnostic can name that entry; its existing post-scan directory/symlink semantics are not redefined as part of this fix.
