- `bindings/dart/search_simpli/tool/build_native.sh` copies the macOS dylib and the Android `.so` into `native/<platform>/` and writes `native/SOURCE-SHA256`; the Dart loader (`lib/src/library_loader.dart`) opens by platform and throws `UnsupportedError('search_simpli: no prebuilt libsearch_simpli for platform …')` elsewhere. On iOS a dynamic library must live in a `.framework` bundle inside the app to be signed and loaded; Flutter's documented form for FFI is `DynamicLibrary.open('name.framework/name')`.
- The app's whisper library already ships this way (`vizhi_whisper.framework`, app task M8-T3): `Info.plist` with `CFBundleIdentifier`, `CFBundleExecutable`, `MinimumOSVersion` 17.0; install name `@rpath/<name>.framework/<name>`.

### Findings (none blocks a ruling)
1. The Report says Zig's linker finds `libSystem.tbd` "through `crt_dir`". Per the Zig source cited under ruling 1, the SDK root (sysroot) is derived from `sys_include_dir` and `crt_dir` is optional for Darwin. The wiring is right; the explanation is not quite. The `build.zig` comment on `appleIosLibcFile` repeats the claim; worth a one-line fix next time `build.zig` is touched.
2. The framework binary imports `___ulock_wait2`, `___ulock_wake`, `___getdirentries64` and `_execve` from libSystem (Zig's standard library; the macOS dylib already imports the same four). The first three are libSystem-internal symbols. A sideloaded or development-signed build does not care. App Store or TestFlight processing may flag them as non-public API. **The orchestrator should know this before M8-T5, if the app ever goes through App Store Connect.**
3. `check_native.sh` pipes `vtool -show-build` into `grep -q` under `set -o pipefail`. If `grep` exits before `vtool` finishes writing, the pipe could report a spurious FAIL. The output is a few lines and this never happened in my 8 runs. It also does not check the example's `jniLibs` copy (not asked).
4. On macOS every `zig build` invocation, `zig build test` included, now runs `xcrun --sdk iphoneos --show-sdk-path` at configure time. On Linux every invocation prints the iOS skip line, as it already does the Android one. This is harmless.
5. The README's package tree does not list `tool/check_native.sh`.
