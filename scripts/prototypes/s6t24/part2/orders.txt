# Control set (fixed now): main2, cl, ci.
# Cells, per corpus (timing-10k, prose-10k, tamil-10k, 10,000 files each, from scripts/gen_timing_corpus.py,

#   open    open_p50 (ss_open + ss_close, 30 timed after 3 warm-ups)
#   query   every warm query p50 (each query of the set under content, filename and both; 300 timed calls)
#   find    every find request p50 (100 timed calls)
#   the first query and the first find after an open are reported beside them, not judged.
# `scan` has no main to compare with and is not a cell; its own cost is ADR 0006 section 9's measurement.
# T = max(0.010 ms, 1 % of main's five-run median for the cell). A cell fails if median_r(head - main) >= T and
# exceeds by >= T the largest median_r(control - main) over the control set (rule of 2026-11-17). Band excursions
# (head above every other build in 3 or more of 5 runs) are tabulated, never failing.
